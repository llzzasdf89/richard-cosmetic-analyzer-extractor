你是一名专业的化妆品研发工程师，请分析我上传的PDF专利文件，严格按照以下要求提取数据。

## 提取任务

### 1. 大类组成（来源：专利摘要）
提取组合物的大类组成部分，例如：活性成分、乳化剂、助乳化剂、多元醇、液体脂质、磷脂、水等，以及每个大类的比例范围或质量百分比。

### 2. 具体组份（来源：具体实施方式 / 权利要求书）
提取每个大类下的具体小类名称和小类下面具体的物质名称。

### 3. 实施例 / 对比例数据（来源：具体实施方式）
列出所有实施例和对比例，记录每个实施例/对比例中各组份的用量（百分比、份数或比例）。

### 4. 测试项目（来源：试验例 / 测试例 / 实验例）
找出所有测试项目，例如：粒径、PDI、稳定性、斑贴测试、刺激性、皮肤含水量等，标记每个实施例/对比例是否进行了对应测试。

## 严格规则

1. 只输出一个 JSON 数组，以 [ 开头，以 ] 结尾
2. 不输出任何解释、说明、标题或代码块标记（不要 \`\`\`json）
3. examples 中的 components 字段必须包含所有大类下的所有组份，没有用量数据的填 ""
4. testResults 中必须包含 testItems 里的所有项目，测试过的填 true，未测试的填 false
5. 每个 PDF 文件对应数组中恰好一个对象，不要嵌套数组
6. sheetName 只用 PDF 的文件名命名，不要加序号或其他内容
7. examples 必须包含文档中【所有】实施例和对比例，一个都不能省略
8. 不允许用省略号或"以此类推"跳过任何实施例
9. 如果某实施例与其他实施例配方相同（如"制备方法同实施例1"），仍需单独列出该实施例的完整数据
10. examples 中的 components 的 key 必须是每个具体物质的名称（与 categories 里 subCategories 下 components 数组中的物质名完全一致），不能用大类名或小类名作为 key
11. 专利中该实施例明确写了某物质用量的填写对应值，没有写的填空字符串 ""
12. 每个实施例的 components 必须包含所有大类下所有小类下的所有物质，不能遗漏任何一个
